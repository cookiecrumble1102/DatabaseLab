**Самописная база данных и минималистичный графический интерфейс к ней**

В качестве предметной области для базы данных рассматривается каталог товаров в магазине. 
Среди основных аттрибутов - артикул (ID), состояние (в продаже/нет), наименование и цена.

Для оптимизации работы базы данных были разработаны механизмы оптимизации, подходящие данной предметной области.
Большинство операций, за исключением выгрузки/сохранения/бэкапов и других файловых операций подобного рода реализованы за константное время.

Чтобы добиться этого, было принято решение хранить служебный файл .idx, в котором указаны байтовые смещения по каждому артикулу.
В момент инициализации создается HashMap, которая считывается из .idx в оперативную память и позволяет выполнять поиск по ключевым полям за константное время (O(N) на предподсчет)

Вставка по ID - O(1) на одну запись;
Изменение строки - O(1) на одну запись;
Удаление строки - O(1) на одну запись;

**Примечание:** Для удаления используется поле состояния. Это позволяет не переписывать байтовые файлы при удалении каждой записи. Удаление производится при открытии файла базы данных за счет служебного файла .idx.

Для поиска по неключевым аттрибутам также реализованы свои хеш-структуры, которые создаются в момент первого запроса по такому аттрибуту, что позволяет избежать лишних операций для тех пользователей, 
которые этот функционал не используют. 

Предподсчет также занимает O(N), а в дальнейшем позволяет получать записи по ключам за O(K+M), 
где K - кол-во записей по первому аттрибуту, M - кол-во записей по второму аттрибуту

**Важное уточнение!** Для цены в данном случае было принято решение использовать TreeMap со встроенной сегментацией, для более простого поиска по диапазону цен, т.к согласно выбранной предметной области,
большинство запросов не подразумевают четкую цену товара, а требуют некий диапазон.

**Реализацию остальных интересующих методов можно посмотреть напрямую в файле "Database.java", где описан класс для работы с базой данных.**
